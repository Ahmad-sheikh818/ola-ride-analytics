# Ola Ride Analytics

Exploratory analysis of **100K+ ride records** using **SQL** and **Python**, digging into ride patterns and service quality.

## What was analyzed

- **Cancellation patterns** — how cancellations distribute across the data
- **Peak demand hours** — when demand rises and falls through the day
- **Driver ratings** — rating patterns and what they say about service quality

## Tech stack

- **SQL** — querying and aggregating the ride data (joins, grouping, window functions)
- **Python (pandas, matplotlib)** — exploratory data analysis and visualization
